# Безопасность

Проект ещё не проходил полный production-аудит. Не используйте его в публичной среде без HTTPS, ограничения доступа, резервного копирования и тестирования авторизации.

**Уязвимости:** не раскрывайте токены, ключи, реальные учётные записи и эксплойты в публичных Issues. Используйте приватное сообщение об уязвимости [GitHub Security Advisories](https://github.com/Zeihos/Slavia-RP/security/advisories/new), если оно доступно, или свяжитесь с владельцем приватно.

- Сайт при Apache 2.4 защищён `Сайт/private/.htaccess`; для Nginx **нужно отдельно закрыть /private/**.
- `Форум/app`, `Форум/storage`, `Вики/app` и `Вики/storage` должны находиться **вне публичного корня сайта**.
- Не загружайте личные сообщения, обращения, БД SQLite, `.env` или ключи установки в Git.
- Ранее ключи первоначальной установки уже попадали в историю репозитория. Они скомпрометированы. Не используйте их и смените пароли на развёрнутых экземплярах. Удаление из последнего коммита **не очищает историю**.
- Делайте бэкапы и проверяйте их восстановление.

Стабильной публично поддерживаемой версии пока нет.
