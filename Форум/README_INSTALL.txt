SLAVIA ROLEPLAY FORUM v1.0
==========================

САМОСТОЯТЕЛЬНЫЙ ФОРУМ (без XenForo)
------------------------------------
Требования: PHP 8.1+ с JSON, session, openssl; место для записи в папку storage.

1. Разместите содержимое каталога public/ в корне сайта (например, public_html/).
2. Каталоги app/ и storage/ разместите на ОДИН уровень ВЫШЕ публичного корня, рядом с ним.
   Важно: эти папки НЕЛЬЗЯ делать доступными напрямую по URL.
3. При необходимости настройте права записи веб-процесса в storage/.
4. В браузере откройте https://ваш-домен/install.php
5. Откройте файл app/install_key.php и скопируйте оттуда ключ установки.
6. Создайте собственного главного администратора и задайте уникальный пароль.
7. Зайдите в «Управление», настройте название, ссылку на сайт, правила и разделы.

После установки install.php больше не открывает страницу установки.
Важное замечание: используется файловое JSON-хранилище. Оно подходит для
начального небольшого сообщества, но для крупного форума рекомендуется
переход на SQL и независимые резервные копии.
Настройте HTTPS и ежедневный бэкап каталога storage/.
Не подменяйте разработкой юридически обязательные правила или документы.

Адаптация XenForo 2.3
--------------------
В каталоге xenforo23_style/ находится XML-стиль на основе загруженного
архива JustAlex и готовые брендовые изображения SLAVIA. Для установки требуется
собственный лицензированный XenForo 2.3 и совместимые компоненты.
Скопируйте содержимое xenforo23_style/upload/ в корень XenForo.
В панели XenForo импортируйте style-SLAVIA-ROLEPLAY.xml как новый стиль.
Импорт стиля НЕ устанавливает XenForo и НЕ создаёт категории/базу данных.
Если используется UI.X / AC.UI, проверьте зависимости и совместимость со своей версией.
Примечание: исходные материалы JustAlex/The ThemeHouse остаются собственностью авторов;
внутри XML сохранена атрибуция исходной работы.
