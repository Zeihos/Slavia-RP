SLAVIA ROLEPLAY FORUM — самостоятельный форум
=============================================

Общая документация по установке: docs/DEPLOY.md (корень репозитория).

PHP 8.1+, поддержка JSON/sessions, права записи в storage.
Укажите web root Форум/public/. Форум/app/ и Форум/storage/ должны
быть недоступны из интернета (вне document root). Включите HTTPS.
Откройте /install.php и введите уникальный ключ, созданный в
Форум/storage/.install-key.php. Получить его можно через SSH/SFTP
или защищённый файловый менеджер, НЕ выкладывая в Git.
После создания администратора проверьте роли, регистрацию и бэкап.

Отдельный каталог xenforo23_style/ содержит адаптацию сторонней темы
для лицензированного XenForo 2.3. Это НЕ самостоятельный форум.
Права на распространение JustAlex/AC.UI/ThemeHouse не подтверждены.
Проверьте их перед использованием или публикацией.
