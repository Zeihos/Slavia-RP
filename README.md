## О проекте

**SLAVIA ROLEPLAY** — будущая многопользовательская RP-игра, где игроки смогут строить собственную историю. Сейчас мы создаём техническую основу: игровой сервер на **Pawn / open.mp** и веб-сервисы, которые будут помогать сообществу.

Мы не выдаём запланированные механики за готовые: фактический статус каждого направления указан ниже.

### Игровой сервер

Первая игровая сборка уже содержит:

- регистрацию и вход с хешированием паролей через bcrypt;
- сохранение персонажа в SQLite (деньги, скин, позиция, время);
- локальный чат и RP-команды `/me`, `/do`, `/b`;
- работу курьера с сохранением доставок и cooldown в SQLite;
- базовый инвентарь, магазин бинтов/аптечек и расходуемые лечебные предметы;
- передачу игровых денег находящимся рядом игрокам с журналом SQLite;
- тестовую покупку личного автомобиля, вызов и сохранение парковки в SQLite;
- базовые топливо, заправку и дверные замки для личного транспорта;
- постоянное гаражное место, постановку автомобиля на хранение, ремонт и эвакуацию за игровые деньги;
- автоматическую компиляцию Pawn в GitHub Actions.

**Важно:** мод успешно компилируется, но полноценное тестирование сервера с несколькими игровыми клиентами ещё не завершено.

### Веб-сервисы

Сайт, форум и база знаний — самостоятельные PHP-приложения. Они могут разворачиваться на отдельных поддоменах, но **пока не имеют общей авторизации и прямой интеграции с игровым сервером**. Платёжная система и реальный мониторинг онлайна не подключены.

## Быстрый старт

<details>
<summary><b>Собрать игровой мод (open.mp / Pawn)</b></summary>

Нужен [sampctl](https://github.com/Southclaws/sampctl) и совместимые зависимости.

~~~bash
cd Игра
sampctl ensure
sampctl build
~~~

Результат: `Игра/gamemodes/slavia.amx`.

Можно также получить тестовую сборку в **[GitHub Actions → Pawn build](https://github.com/Zeihos/Slavia-RP/actions/workflows/pawn-ci.yml)**: выбери успешный запуск и скачай артефакт `SLAVIA-RP-openmp-AMX` (хранится ограниченное время).

Для запуска сервера потребуется установленный open.mp и соответствующий `samp-bcrypt`. Подробная инструкция — [в документации игрового сервера](./docs/GAME_SERVER.md).

</details>

<details>
<summary><b>Развернуть сайт, форум или Wiki (PHP)</b></summary>

Требуется **PHP 8.1+**, HTTPS и каталоги с правом записи.

| Сервис | Document root |
| :--- | :--- |
| Сайт | `Сайт/` |
| Форум | `Форум/public/` |
| База знаний | `Вики/public/` |

Сначала обязательно изучи **[инструкцию по развёртыванию](./docs/DEPLOY.md)**: у каждого приложения собственные данные и ключ установки, а приватные каталоги нельзя публиковать в интернете.

</details>
