# SLAVIA ROLEPLAY

**Независимый RolePlay-проект в разработке.** Репозиторий содержит игровой мод для open.mp (Pawn), сайт, форум, Wiki и фирменные материалы. Это **основа для тестирования**, а не готовый публичный сервер.

## Быстрый старт

**Игровой сервер:** установите [sampctl](https://github.com/Southclaws/sampctl), затем:

~~~bash
cd Игра
sampctl ensure
sampctl build
~~~

Полученный `gamemodes/slavia.amx` также публикуется в артефактах [Pawn build](https://github.com/Zeihos/Slavia-RP/actions/workflows/pawn-ci.yml) на 14 дней. Для запуска необходимы open.mp и совместимый `samp-bcrypt`. Сборка **не** подтверждает запуск с игровыми клиентами. Подробности — [GAME_SERVER.md](./docs/GAME_SERVER.md).

**Веб-часть:** три независимых PHP 8.1+ приложения с отдельными web roots: `Сайт/`, `Форум/public/` и `Вики/public/`. Начните с [DEPLOY.md](./docs/DEPLOY.md), особенно если сайт уже работает.

## Ограничения

Нет готового мобильного клиента, подтверждённого публичного сервера, работающих платежей, сквозной авторизации, полноценного античита и большинства запланированных игровых механик. Сайт/форум/Wiki используют файловые хранилища. Перед публичным запуском обязательны тесты безопасности, ручные игровые и браузерные тесты, резервное копирование и проверка прав на сторонние материалы.

**Статус:** активная разработка. Зелёный значок GitHub Actions означает успешную автоматическую проверку, но не готовность к релизу.
