# Roadmap SLAVIA ROLEPLAY

| Компонент | Подтверждено | Нужно сделать |
| --- | --- | --- |
| Игровой мод | Сборка Pawn CI | Запустить open.mp, проверить 2 клиента |
| Регистрация и SQLite | Код написан | Переподключение, ошибки, сохранения |
| RP-чат и курьер | Код написан | Ручные игровые тесты |
| Сайт | PHP lint и HTTP smoke | Визуальные браузерные и production-тесты |
| Форум | PHP lint и HTTP smoke | Модерация, нагрузка, спам-защита |
| Wiki | PHP lint и HTTP smoke | Проверка материалов и редактора |
| Резервные копии | Нет автоматизации | Бэкап + восстановление |
| Античит, права администрации | Не готово | Разработка и аудит |
| Фракции, дома, бизнесы, транспорт | Не готово | ТЗ и реализация |
| Мобильный клиент | Не готово | План совместимости |
| Интеграция аккаунтов | Не готово | Архитектура API, защита доступа |

**Ближайший этап:** тестовое подключение двух игроков, регрессия входа/выхода, регистрация, сохранение денег, цикл курьера; затем проверка PHP-приложений на staging с HTTPS. Версии с пометкой «собрано» не считать публичным релизом.

## Надёжность — ревизия ноября 2026

- Исправлена обработка повреждённых файлов данных сайта и Wiki: запись не должна стирать существующие повреждённые данные.
- После смены пароля другие авторизованные сеансы теряют доступ к панели/аккаунту.
- В CI добавлены изолированные регрессионные проверки файлового хранения и сеансов.
- **Остаётся проверить:** полные действия в браузере, установку на реальном сервере, игровые подключения, миграции и полноценные резервные копии.


### Игровой мод — этап 0.2.0
- Курьерский прогресс и время ожидания перенесены в SQLite, награда и статистика сохраняются транзакционно.
- Добавлены /jobs, /jobstats и транслитерированные алиасы команд.
- Начало курьерской работы ограничено местом старта, введена дополнительная проверка позиции на чекпоинтах.
- Сохраняется задача: ручное тестирование работы игрового сервера с двумя клиентами, перезапуск сервера и проверка реальной выдачи наград.


### Игровой мод — этап 0.3.0
- Реализован первый двухпредметный инвентарь (бинты и аптечки), покупка в точке возле мэрии и использование предметов для лечения.
- Количество предметов хранится в SQLite, изменение денег и остатков выполняется транзакционно.
- Добавлены команды `/inv`, `/inventory`, `/shop`, `/buybandage`, `/buymedkit`, `/usebandage`, `/usemedkit`.
- Следующие задачи: тестирование в игре, полноценная предметная система с предметами разных типов и серверный интерфейс магазина.


### Игровой мод v0.4.0 — личный транспорт
- В код добавлены покупка Manana/Premier, сохранение владения и парковки в SQLite.
- Покупка списывает игровые деньги транзакционно; нельзя приобрести второй автомобиль для одного персонажа.
- Команды: `/cars`, `/buycar 1`, `/buycar 2`, `/mycar`, `/vspawn`, `/vpark`, `/vstore`.
- Требуются реальные игровые тесты: два клиента, парковки, удаление на выходе и повторный вход.
- Дальше: устойчивые парковочные слоты, конфигурируемый автосалон, гараж, топливо, блокировка автомобиля и журнал собственности.
